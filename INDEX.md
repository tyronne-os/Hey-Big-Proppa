# BIG PROPPA — repo index

Canonical source of truth: **github.com/tyronne-os/Hey-Big-Proppa** (`main`; work branches `claude/*`).
Everything below is either in this repo or a backup of it. Update this file when a location changes.

## Where things live and save

| What | Location | Saved to |
|---|---|---|
| Backend API (FastAPI) | `backend/` | GitHub |
| Frontend (React/Vite) | `frontend/src/` | GitHub |
| Landing page (HOME) | `frontend/public/home/` (served at `/home/index.html`); `landing/` is the same page's design source — keep both in sync | GitHub |
| NFL data lake (CSV) | `lake/gold/nfl/` | GitHub (tracked) + HF dataset `AIBRUH/big-proppa-lake` via `scripts/backup_lake_to_hf.py` |
| ESPN stream snapshots | `lake/gold/espn/` | **Not saved anywhere** — gitignored, not in the Docker image; regenerated by MY BOO's staff at runtime |
| Raw / derived lake layers | `lake/bronze/`, `lake/silver/` | Not saved (gitignored; rebuild with `scripts/build_*.py`) |
| SQL schemas | `sql/` | GitHub |
| Data source registry (Utility Room) | `junk_drawer/sources.yaml`, `docs/UTILITY_ROOM.md` | GitHub |
| Build / backtest scripts | `scripts/` | GitHub |
| Docs and handoffs | `docs/` (start with `docs/HANDOFF.md`; old sync log `docs/SYNC_LOG.md`) | GitHub |

## Deployed copies

| Where | What | How it updates |
|---|---|---|
| Hugging Face Space (Docker, port 7860) | The running site | Built from root `Dockerfile`. It copies `frontend/dist/`, which is gitignored here, so the Space repo carries a pre-built `dist/` — rebuild with `npm run build` before pushing to the Space |
| HF dataset `AIBRUH/big-proppa-lake` (private) | Backup of `lake/gold/nfl/*.csv` | Run `python scripts/backup_lake_to_hf.py` (needs `HF_TOKEN`) |

Both are redundancy only; GitHub wins any disagreement.

## Local dev

Reserved ports **8085–9005**. Frontend **8085**, backend **8086**. Run `./scripts/start.sh` (or `stop`).
Backend needs `backend/.venv` (`pip install -r backend/requirements.txt`).

## Known gaps

- `lake/gold/espn/` is not persisted (see table). Polls/portal "seen" state resets when the Space restarts.
- Local runs of the backend rewrite tracked lake files (`tr_runs.json`, `myboo_*`) — review before committing; they are runtime state.
- `README.md` deployment text mentions a Node build stage; the actual `Dockerfile` uses a pre-built `dist/`.
